# 專案特定細則：警務影像轉換器 (Police Image Converter Rules)

> [!IMPORTANT]
> 本專案嚴格遵循「全域大腦 v2.1.0 (Tech Lead)」。由於涉及警務蒐證影像，**全本機離線運算 (Offline-First)** 是我們不可妥協的底線，嚴禁任何資料上傳至第三方伺服器。溝通與程式註解請 100% 使用台灣繁體中文，保持直率專業的 Tech Lead 口吻，避免 AI 模板用語。

## 1. 核心開發準則 (Technical Standards)
- **單檔交付架構**：堅持 All-in-One HTML 架構，所有邏輯、樣式與資源必須俐落地封裝於 `index.html`，以利隨插即用。
- **配置管理集中化**：所有的核心參數（如 DPI、重疊公分、銳化強度）都必須統一定義在 `CONFIG_MANAGER.DEFAULT_CONFIG` 中，禁止散落各處的魔術數字。
- **效能優化與非同步處理**：面對長截圖處理，必須徹底落實 `async/await` 配合 `Promise` 處理 Blob 生成，絕對不允許阻塞瀏覽器主執行緒 (UI Thread)。

## 2. 動態配置與 UI 互動 (UI-Driven Pattern)
- **參數連動**：任何新增的圖像處理參數，必須同步反映在側邊進階設定面板 (`configPanel`)。
- **即時回饋機制**：UI 必須具備穩定可靠的 `syncConfigToUI` 邏輯，確保 `localStorage` 的設定值與滑桿 (Range Input) 狀態分毫不差地即時對應。
- **視覺回饋與極致美學**：
  - 介面設計必須告別陽春感，採用現代化、精緻排版的 UI。
  - 轉換過程中，務必使用設計優良的進度條 (`progressBar`) 清晰呈現當前處理張數與狀態。

## 3. 影像處理邏輯 (Image Processing Logic)
- **長截圖判定與切片**：採用 `ratioThreshold` 作為分割判準，超過此比例之影像必須執行精準的自動切片。
- **重疊裁切 (Overlap)**：為了確保蒐證文字的完整性，切片起始點必須包含依據公分換算 (`overlapCM`) 的重疊區域，確保文字銜接天衣無縫。
- **畫質保證**：
  - **DPI 轉換**：必須依據輸出畫質設定，自動計算目標公分 (`targetWidthCM`, `targetHeightCM`) 對應的像素。
  - **銳化濾鏡**：使用 3x3 卷積核 (Convolution Kernel) 進行文字邊緣強化，並將混合強度開放為可調參數。

## 4. 安全與隱私 (Privacy & Security)
- **外部資源控管**：僅限使用認可之 CDN (如 cdnjs, jsdelivr)，嚴禁本地相對路徑依賴，確保檔案在任何離線或封閉環境皆可即時雙擊執行。
- **嚴格本機處理**：所有轉檔邏輯（HEIC2any, JSZip）必須在客戶端瀏覽器內完成，嚴禁夾帶任何會將資料外傳的 API 呼叫。

## 5. UI/UX 與視覺設計規範
- **字體規範**：優先使用 `Noto Sans TC` 或系統預設的高質感無襯線字體，確保公務環境顯示穩定且具現代感。
- **移動優先 (Mobile-First)**：即使是進階設定面板，也必須在行動載具上提供順暢、易用的操作體驗。
- **語系與防禦性**：介面文字、提示語、下載檔名必須 100% 採用台灣繁體中文，並防範任何非預期的非法字元寫入檔名。
