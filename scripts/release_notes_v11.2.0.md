## 🏆 v11.2.0 里程碑：手機長截圖分頁輔助、鑑識圖示與免安裝單檔發布

專為第一線外勤與警務鑑識同仁打造之 **Windows 原生免安裝影像處理工具箱**。
本版本正式導入「**手機長截圖分頁輔助**」，精準解決 LINE / 簡訊對話紀錄長截圖貼入 Word 偵查報告書時比例失真、字體模糊或切線漏字的痛點；同時全面升級高解析警務鑑識圖示與 I/O 記憶體安全防護。

---

### 🚀 快速下載與使用說明 (Download & Run)

* **免安裝單檔（推薦）**：直接下載下方 Assets 中的 **`PoliceImageToolkit.exe`**，放置於桌面或任意資料夾，雙擊即可直接執行（0.1 秒秒開）。
* **ZIP 壓縮包**：若您的瀏覽器限制直接下載 `.exe`，可下載 **`PoliceImageToolkit-v11.2.0-win-x64.zip`**，解壓縮後即可使用。
* **零依賴環境**：採 Self-Contained 獨立封裝，電腦**不需要**預先安裝 .NET Runtime 或其他軟體。
* **100% 離線本機處理**：所有影音與圖片解碼運算均在本機 CPU 執行，無任何聯網傳輸，確保司法證物隱私安全。

> 💡 **若出現 SmartScreen 防護提示**：「Windows 已保護您的電腦」➜ 請點擊 **「其他資訊」** ➜ **「仍要執行」** 即可。

### ✨ 重點更新特色

#### 1. 📜 手機長截圖分頁輔助 (Long Screenshot Splitter)
- **Word 報表圖框精準比例切分**：以報告書常用圖框實體比例（預設 `8 cm × 17.5 cm`、重疊 `5 mm`）自動計算最佳裁切頁數。
- **前後頁重疊遮罩防漏字**：相鄰頁面保留重疊像素，避免關鍵字句恰好落在分頁切線上；預覽區以黃色虛線遮罩標示（僅供預覽，不輸出至圖檔）。
- **原始像素 1:1 零失真**：堅持原始點陣裁切，不重新取樣或縮放，維持原始長截圖文字絕對清晰度。
- **低解析度常駐警示**：原圖寬度低於 `600px` 時即時提示放進 Word 可能模糊，引導向當事人索取原始檔案。

#### 2. 🛡️ 專屬警務鑑識品牌圖示 (Forensic Shield Icon)
- 導入全新 256x256 高解析盾牌與相機鏡頭警務鑑識圖示（`app.ico`）。
- 內建 Windows Shell `SHChangeNotify` 圖示快取即時更新，發布後圖示清晰不模糊。

#### 3. ⚡ 影像與視訊服務強健度（Robustness）全面強化
- **100M 像素上限防護**：圖片轉檔與長截圖解碼加入像素安全上限，防止惡意畸形圖檔造成記憶體崩潰 (OOM)。
- **原子化檔名防衝突**：轉檔與截圖存檔全面採用 `FileMode.CreateNew`，避免多工或連按覆寫同名證物。
- **例外殘檔自動清理**：轉檔或截圖異常中斷時自動清理未完成殘檔，確保輸出資料夾乾淨。
- **寬螢幕自適應佈局**：視訊截圖在寬度 $\ge 1450\text{px}$ 螢幕下自動切換為雙欄大型比對視窗，對照視野大幅提升。

#### 4. 🧹 專案純淨化
- 移除歷史純網頁版檔案，全面收斂為 C# .NET 8 LTS WPF 原生主線。
